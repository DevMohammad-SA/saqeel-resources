# مكتبة ملفات المتطوعين - جمعية صقيل لتنمية الشباب
منصة ويب ثابتة (Static Site) مخصصة لتنظيم وتوفير التراخيص الرسمية، الشهادات، وشعارات الجهات الداعمة لمتطوعي جمعية صقيل لتنمية الشباب، مع لوحة تحكم مدمجة لإدارة وتحديث المحتوى بسهولة.

## التقنيات المستخدمة
- **الواجهة الأمامية:** HTML5, CSS3, Vanilla JavaScript (تصميم متجاوب ومتوافق مع اللغة العربية RTL).
- **إدارة المحتوى (CMS):** Decap CMS (مبنية على Git).
- **المصادقة والإدارة:** Netlify Identity و Git Gateway.
- **التخزين والاستضافة:** GitHub (مستودع الأكواد) و Netlify (الاستضافة والنشر التلقائي).

## هيكل المشروع
المشروع يعتمد على هيكل ملفات منظم وخفيف:
```text
├── admin/
│   ├── config.yml    # إعدادات وهيكل لوحة التحكم[cite: 2]
│   └── index.html    # واجهة ملفات الـ CMS
├── assets/
│   ├── css/          # ملفات التنسيق (style.css)[cite: 1]
│   ├── img/          # الشعارات والعلامات البصرية[cite: 1]
│   └── js/           # سكربتات جافاسكريبت (main.js)[cite: 1]
├── data/
│   └── files.json    # قاعدة بيانات خفيفة لتخزين التراخيص والشعارات[cite: 1]
└── index.html        # الصفحة الرئيسية للموقع[cite: 1]

```

## إدارة المحتوى (CMS)

تم دمج لوحة تحكم لتسهيل إضافة أو تعديل التراخيص والشعارات دون الحاجة لتعديل الكود البرمجي:

1. الانتقال إلى مسار لوحة التحكم: `/admin/`
2. تسجيل الدخول عبر حساب Netlify Identity المعتمد.
3. التعديل على البيانات، حيث يقوم النظام تلقائياً بحفظ التغييرات ورفعها كـ Commit في مستودع GitHub وتحديث ملف `data/files.json`.



## التشغيل المحلي للتطوير

الموقع لا يتطلب بيئة تشغيل معقدة:

1. استنساخ المستودع:
```bash
git clone https://github.com/DevMohammad-SA/saqeel-resources.git
```


2. فتح المجلد باستخدام أي محرر أكواد (مثل VS Code).
3. تشغيل المشروع باستخدام أداة معاينة محلية (مثل Live Server).

## النشر (Deployment)

الموقع مربوط تلقائياً بخدمة Netlify؛ بمجرد عمل Push لأي تعديل على الفرع الرئيسي (`master` أو `main`)، يتم تحديث الموقع وبناؤه خلال ثوانٍ معدودة.
